# HTML

## Technology Overview

HTML structures web content with semantic elements, headings, forms, media, links, and document metadata.

## Learning Objectives

- Understand the core concepts of HTML.
- Practice each topic with focused exercises.
- Build mini projects and portfolio-ready work.
- Document lessons clearly for GitHub and content creation.

## Why I Am Learning This Technology

HTML is the foundation of every front-end interface and is essential for accessibility, SEO, and clean page structure.

## Current Roadmap

- Links

- Semantic HTML
- Accessibility Basics

## Folder Explanation

- Assets stores images, icons, fonts, and visual resources.
- Exercises contains topic-based practice folders.
- Notes contains written explanations for each roadmap topic.
- Projects stores mini projects, portfolio projects, and challenges.
- Source stores books, documentation links, and reference material.
- Progress.md tracks completed learning milestones.

## GitHub Usage

Commit finished exercises, notes, and projects with clear messages. Keep this folder organized so recruiters and collaborators can understand the learning path quickly.

## How Exercises Should Be Organized

Each exercise should live in a numbered topic folder, include a short README.md, and contain the appropriate practice file for the technology. Keep experiments focused on the topic being studied.
