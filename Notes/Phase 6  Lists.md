PHASE 6 — LISTS

72. "<ul>"

Function: Creates an unordered list where item order is not important.
Example:

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

73. "<ol>"

Function: Creates an ordered list where item order is important.
Example:

<ol>
    <li>Learn HTML</li>
    <li>Learn CSS</li>
    <li>Learn JavaScript</li>
</ol>

74. "<li>"

Function: Defines an individual item inside a list.
Logic: "<li>" is normally used inside "<ul>" or "<ol>".
Example:

<ul>
    <li>HTML</li>
    <li>CSS</li>
</ul>

75. Ordered List Attributes

Function: Controls the numbering behavior of an ordered list.
Example:

<ol start="5">
    <li>HTML</li>
    <li>CSS</li>
</ol>

76. Nested Lists

Function: Creates a list inside another list item.
Logic: Use nested lists to represent hierarchical information.
Example:

<ul>
    <li>Frontend
        <ul>
            <li>HTML</li>
            <li>CSS</li>
        </ul>
    </li>
</ul>

77. "<dl>"

Function: Creates a description list for terms and their descriptions.
Example:

<dl>
    <dt>HTML</dt>
    <dd>Structures web content.</dd>
</dl>

78. "<dt>"

Function: Defines a term or name in a description list.
Example:

<dl>
    <dt>HTML</dt>
</dl>

79. "<dd>"

Function: Provides the description or value for a term in a description list.
Example:

<dl>
    <dt>HTML</dt>
    <dd>Structures web content.</dd>
</dl>
