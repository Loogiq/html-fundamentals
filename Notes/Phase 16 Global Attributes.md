PHASE 16 — GLOBAL ATTRIBUTES

192. "id"

Function: Gives an element a unique identifier.
Logic: Use "id" when one specific element needs to be identified.
Example:

<p id="intro">Welcome to HTML.</p>

193. "class"

Function: Assigns one or more elements to a reusable group.
Logic: Use "class" when multiple elements share the same styling or behavior.
Example:

<p class="text">Hello</p>
<p class="text">World</p>

194. "style"

Function: Applies CSS directly to an HTML element.
Example:

<p style="color: red;">Hello</p>

195. "title"

Function: Provides additional advisory information about an element.
Example:

<button title="Save your work">Save</button>

196. "lang"

Function: Specifies the language of an element's content.
Example:

<p lang="ja">こんにちは</p>

197. "dir"

Function: Specifies the text direction of an element.
Example:

<p dir="rtl">مرحبا</p>

198. "hidden"

Function: Hides an element from the rendered page.
Example:

<p hidden>This is hidden.</p>

199. "data-*"

Function: Stores custom data on an HTML element.
Logic: JavaScript can later read the custom data.
Example:

<button data-user-id="123">Profile</button>

200. "contenteditable"

Function: Allows the user to edit the content of an element.
Example:

<p contenteditable="true">Edit this text.</p>

201. "draggable"

Function: Specifies whether an element can be dragged.
Example:

<div draggable="true">Drag me</div>

202. "spellcheck"

Function: Specifies whether the browser should check spelling and grammar.
Example:

<textarea spellcheck="true"></textarea>

203. "tabindex"

Function: Controls whether an element can receive keyboard focus and its focus order.
Example:

<button tabindex="0">Click me</button>

204. "translate"

Function: Specifies whether the element's text should be translated by translation tools.
Example:

<p translate="no">LOOGIQ</p>
