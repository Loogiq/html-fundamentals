PHASE 18 — HTML + SEO

215. Semantic Structure for SEO

Function: Helps search engines understand the structure and meaning of page content.
Logic: Use semantic HTML to clearly describe the purpose of content.
Example:

<main>
    <article>
        <h1>Learn HTML</h1>
        <p>HTML structures web content.</p>
    </article>
</main>

216. "<title>" for SEO

Function: Provides the page title used by browsers and commonly used by search engines in search results.
Example:

<title>Learn HTML for Beginners</title>

217. Meta Description

Function: Provides a short description of the webpage for search engines and search-result snippets.
Example:

<meta name="description" content="Learn HTML from beginner to advanced.">

218. Heading Hierarchy

Function: Organizes content into a clear hierarchy for users and search engines.
Logic: Use headings according to content structure, not simply for visual size.
Example:

<h1>Learn HTML</h1>
<h2>HTML Basics</h2>
<h3>HTML Elements</h3>

219. Link Semantics

Function: Helps search engines and users understand the purpose and relationship of links.
Example:

<a href="/html-course">Learn HTML</a>

220. Image "alt" Text

Function: Provides a text alternative for images and helps search engines understand image content.
Example:

<img src="html.png" alt="HTML code example">

221. Structured Content

Function: Organizes content clearly so browsers, users, and search engines can understand it.
Example:

<article>
    <h1>HTML Tutorial</h1>
    <section>
        <h2>HTML Basics</h2>
        <p>Learn HTML fundamentals.</p>
    </section>
</article>

222. Crawlable HTML

Function: Makes important page content and links accessible to search engine crawlers.
Logic: Use normal HTML links and meaningful content that crawlers can discover.
Example:

<a href="/about">About Us</a>
