PHASE 1 — HTML FUNDAMENTALS

1. HTML Element

Function: Represents a complete piece of HTML content.
Logic: An element usually consists of a tag and its content.
Example:

<p>Hello</p>

2. HTML Tag

Function: Tells the browser what type of content an element represents.
Example:

<p>

3. Opening Tag

Function: Marks where an HTML element starts.
Example:

<p>

4. Closing Tag

Function: Marks where an HTML element ends.
Example:

</p>

5. HTML Nesting

Function: Places one element inside another element.
Logic: HTML elements can form a parent → child structure.
Example:

<div>
    <p>Hello</p>
</div>

6. Parent, Child & Sibling Elements

Function: Describes the relationships between HTML elements.
Logic: An element containing another is the parent; the contained element is the child; elements sharing the same parent are siblings.
Example:

<div>
    <p>Hello</p>
    <p>World</p>
</div>

7. HTML Attributes

Function: Provides additional information or configuration for an element.
Example:

<a href="https://example.com">Visit</a>

8. Attribute Value

Function: Defines the specific value assigned to an attribute.
Example:

<a href="https://example.com">

"href" = attribute
""https://example.com"" = attribute value

9. Boolean Attributes

Function: Represents a true/false setting by its presence or absence.
Logic: If the attribute exists, it is enabled.
Example:

<input disabled>

10. Global Attributes

Function: Provides attributes that can be used on most HTML elements.
Example:

<p id="intro" class="text">Hello</p>

"id" and "class" are global attributes.
