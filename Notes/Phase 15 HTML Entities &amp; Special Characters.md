PHASE 15 — HTML ENTITIES & SPECIAL CHARACTERS

184. HTML Character References

Function: Represents special characters that have a special meaning in HTML.
Logic: Use character references when a character could be interpreted as HTML syntax.
Example:

<p>Use &lt;p&gt; for a paragraph.</p>

185. "&lt;"

Function: Displays the "<" character as text.
Example:

<p>&lt;h1&gt;Hello&lt;/h1&gt;</p>

186. "&gt;"

Function: Displays the ">" character as text.
Example:

<p>5 &gt; 3</p>

187. "&amp;"

Function: Displays the "&" character as text.
Example:

<p>HTML &amp; CSS</p>

188. "&quot;"

Function: Displays a double quotation mark (""").
Example:

<p>&quot;Hello&quot;</p>

189. "&apos;"

Function: Represents an apostrophe ("'").
Example:

<p>It&apos;s HTML.</p>

190. Non-Breaking Space

Function: Creates a space that the browser does not normally use as a line-break point.
Example:

<p>Hello&nbsp;World</p>

191. Unicode Characters

Function: Represents characters from a wide range of writing systems and symbol sets.
Logic: HTML documents use Unicode, allowing languages such as Japanese, Arabic, Chinese, and Indonesian.
Example:

<p>こんにちは 世界 مرحبا</p>
