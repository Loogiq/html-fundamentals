PHASE 3 — TEXT & HEADINGS

21. "<h1>"

Function: Defines the main heading of a page.
Logic: Use it for the page's primary heading.
Example:

<h1>Learning HTML</h1>

22. "<h2>"

Function: Defines a second-level heading.
Example:

<h2>HTML Basics</h2>

23. "<h3>"

Function: Defines a third-level heading.
Example:

<h3>HTML Elements</h3>

24. "<h4>"

Function: Defines a fourth-level heading.
Example:

<h4>HTML Tags</h4>

25. "<h5>"

Function: Defines a fifth-level heading.
Example:

<h5>Examples</h5>

26. "<h6>"

Function: Defines a sixth-level heading.
Example:

<h6>Notes</h6>

27. "<p>"

Function: Defines a paragraph of text.
Example:

<p>I am learning HTML.</p>

28. "<br>"

Function: Creates a line break.
Example:

Hello<br>World

29. "<hr>"

Function: Represents a thematic break between sections of content.
Example:

<p>Chapter 1</p>
<hr>
<p>Chapter 2</p>

30. "<strong>"

Function: Indicates that the content has strong importance.
Example:

<strong>Important!</strong>

31. "<em>"

Function: Indicates emphasized content.
Example:

<em>This is important.</em>

32. "<b>"

Function: Draws attention to text without adding importance.
Example:

<b>Product Name</b>

33. "<i>"

Function: Represents text in an alternate voice, mood, or terminology.
Example:

<i>Homo sapiens</i>

34. "<u>"

Function: Represents text with a non-textual annotation.
Example:

<u>Misspelled</u>

35. "<s>"

Function: Represents content that is no longer accurate or relevant.
Example:

<s>$50</s> $30

36. "<mark>"

Function: Highlights text because it is relevant to the current context.
Example:

<mark>Important keyword</mark>

37. "<small>"

Function: Represents side comments or small-print text.
Example:

<small>Terms and conditions apply.</small>

38. "<sub>"

Function: Displays subscript text.
Example:

H<sub>2</sub>O

39. "<sup>"

Function: Displays superscript text.
Example:

x<sup>2</sup>

40. "<blockquote>"

Function: Represents a long quotation from another source.
Example:

<blockquote>
    Learning never stops.
</blockquote>

41. "<q>"

Function: Represents a short inline quotation.
Example:

<p>He said, <q>Hello</q>.</p>

42. "<cite>"

Function: Identifies the title of a creative work.
Example:

<cite>The Great Gatsby</cite>

43. "<code>"

Function: Represents a short piece of computer code.
Example:

<code>console.log("Hello");</code>

44. "<pre>"

Function: Preserves whitespace and line breaks in preformatted text.
Example:

<pre>
Hello
    World
</pre>

45. "<kbd>"

Function: Represents user input from a keyboard or other input device.
Example:

Press <kbd>Ctrl</kbd> + <kbd>C</kbd>

46. "<samp>"

Function: Represents sample output from a computer program.
Example:

<samp>File not found.</samp>

47. "<var>"

Function: Represents a variable in a mathematical or programming expression.
Example:

<var>x</var> = 10

48. "<abbr>"

Function: Represents an abbreviation or acronym.
Example:

<abbr title="HyperText Markup Language">HTML</abbr>

49. "<time>"

Function: Represents a specific time or date.
Example:

<time datetime="2026-08-15">August 15, 2026</time>

50. "<address>"

Function: Represents contact information for a person, organization, or webpage.
Example:

<address>
    Contact: hello@example.com
</address>
